# MCP Architecture and Interiors XA Energy - Release notes

Current version: **1.83.0**. You can read these notes in the program: File > Release notes... The version number is shown in the installer, in the installer file name
(`MCP_XA_Energy_Setup_x.y.z.exe`) and in Windows' list of installed programs.

## What is new since the first version (1.0.0)

### New features
- **Rules, 1.83.0**: the sixth square on the start screen is now **Rules** (it was Council pack). It opens three squares: Council pack (as before), Stand rules and Council guidelines. The last two are marked WIP: the squares are in place, the checks themselves are still to be built.
- **Live link with the glass of your IFC, 1.82.7**: Archicad's live link cannot see the glass or which panes open (the IFC reads it from the 3D model). New button in the live panel: **Take glass and opening from an IFC file...**. Pick an IFC export of the same project once: every window and door with the same ID then gets its glass area, panes and opening from the IFC, exactly as the IFC import does, while the ID, size, count and rooms keep following Archicad live. If you already imported the IFC with I have an IFC model, that is used too. What you set in the hover pop-up is still kept.
- **Live link: one row per ID, 1.82.6**: every window or door with the same ID in Archicad (ID and categories > ID, like W3) is now one line in the schedule with the total count, instead of W3, W3_2, W3_3 when sizes or glass differ slightly. If they do differ, the most common size is used and the row's note says so.
- **Live link reads the window library part, 1.82.5**: for each window type the program asks Archicad (through Tapir) for the library part settings and reads the glazed area (or works it out from the frame width), the number of panes and how they open. The opening panes and ventilation then show in the hover pop-up as soon as the window appears, marked as read from the library part so you can check them. If Archicad has no glass area in the model, this is used. Your own changes in the pop-up are still kept.
- **Live link, from your Archicad log, 1.82.4**: Tapir was found and works. Windows and doors now take the ID you typed in Archicad (W6, D2) from Tapir, and the window or door is put in a room by where it sits against the room outline, because Archicad itself gave no room links (every room came back empty). Diagnose now also saves the full details and GDL parameters of one window, door and room, and the list of all property names, so the glazed area can be matched next.
- **Live link: real names and glazed area, 1.82.3**: windows and doors now come in with the name you gave them in Archicad (Element ID, else the library part name) instead of W1800x600, and the glazed area is read from the model when Archicad has it. Hovering a window in the schedule or the Energy (XA) glass table now shows the drawing and the pop-up where you set how each pane opens (ventilation) and the glazed %, also when the model comes live from Archicad. What you set is kept while the live link refreshes; only the quantity follows Archicad. If it still shows typical values, press Diagnose and save the log: it lists the properties Archicad offers.
- **Tapir with the installer, 1.82.2**: the setup now carries the Tapir add-on installer for Archicad (the build fetches the latest one) and, on a normal install, offers to run it on the last page (tick: Install the Tapir add-on into Archicad). Automatic updates do not run it. The Live design check has an Install the Tapir add-on button as well. Close Archicad first; Tapir's installer finds your Archicad versions itself.
- **Live design check, 1.82.1**: tested on a real Archicad it read the rooms but no windows or doors. Now: Tapir is detected by trying one of its commands (not only by asking), window and door sizes are looked up from Archicad's property names, with the candidates written to the log, a new Diagnose button lists what the link can see (element counts and the width, height, window, door and wall properties), and an Ignore rooms box (default: gross area, site, sqm, typical, total) leaves non-rooms such as gross areas and the site out of the checks.
- **Live design check from Archicad, 1.82.0 (WIP, not tested on a real Archicad yet)**: File > Live design check (WIP)... (Ctrl+Shift+L, with WIP mode on) opens a narrow window to keep beside Archicad. Press Start live and every few seconds (you choose 1 to 60) it reads the open project: the rooms (zones) with their areas and floors, and every window and door with its size, and which room each belongs to (the Tapir add-on is needed to tie openings to rooms). When something changes it replaces the Light and Ventilation windows, doors and rooms and the Area schedule, runs the Light and Ventilation and Energy (XA) window checks, and lists where the design breaks: rooms that fail natural light or ventilation (with the numbers), glazing over the limit, floors where the XA glazing needs a calculation, and rooms with no window or door. The first time, it asks before taking over those tables. Glazed and openable percentages are typical values until you set them per window type. Walls (cavity or solid), coverage and the window facing are not read from Archicad yet. Save the log keeps what Archicad answered, for when something does not match your Archicad version.
- **Archicad link relabelled WIP, 1.81.1**: the experimental switch is now File > WIP mode (work in progress features), and the link is File > Archicad link (WIP)... Same function as 1.81.0.
- **Archicad link, WIP mode, 1.81.0 (work in progress)**: File > WIP mode (work in progress features) switches it on; then File > Archicad link (WIP)... (Ctrl+Shift+A) connects to the Archicad project that is open on the same computer. Connect and test shows the Archicad version, whether the Tapir add-on is installed and how many rooms, slabs and meshes it can see. Rooms to Area schedule brings the Archicad rooms (zones) with name, number and area, and the storey name when Tapir is installed. Stand outline to Building lines draws the stand from a Slab, Mesh or Zone outline (needs Tapir) and turns it horizontal. Nothing is changed in Archicad. Save the log keeps what was exchanged, which helps when something does not match your Archicad version. Not tested against a real Archicad yet. The folder archicad_addon contains the source for a small Archicad menu add-on (MCP Tools > Open MCP Architecture & Interiors) that starts the program; it has to be built with Graphisoft's Development Kit.
- **Street names and automatic building lines, 1.80.3**: each boundary in Building lines now has a Name column (for example Baron van Reden Street or Jacob Street). The name shows on the plan above the kind and building line, and in the reports and the departure motivation. Choosing Street, Side or Rear for a boundary fills in that kind's usual building line (street 4.5 m, side 2 m, rear 3 m, set in the boxes above the table) and you can still type any other number. A name with Street, Road, Avenue, Drive, Laan, Straat, Weg and similar words in it makes that boundary the street by itself. You can also right-click a boundary line in the plan: This is the street, a side, the rear, Name this boundary, or Change the building line.
- **Rotate the plan, buildings and a north arrow, 1.80.2**: the plan now has a north arrow (also in the PDF report). Drag it round to point north (hold Shift to step in 15 degrees), or right-click it for 90, 45, 15 and 1 degree turns or a custom direction; it can be hidden. Right-click a building in the plan to turn it in steps, snap its angle to 90, 45 or 15 degrees, line it up with the nearest boundary, type any angle, place it with a ruler or remove it. Right-click empty plan to turn the whole plan (stand, survey drawing and buildings, and the north arrow with them) in steps or by a custom angle, or to turn the longest boundary horizontal again. The same choices are in three menus above the plan (Rotate plan, North arrow, Rotate building). The IFC footprint dialog has a new tick, Straighten it; leave it off to keep the direction the model was drawn in.
- **Survey drawn for you, always horizontal, and a ruler, 1.80.1**: when you load the survey, the stand is now drawn automatically from the biggest closed outline (the sheet border is ignored), and the whole plan is turned so the longest boundary runs left to right, however the drawing came in. Traced or picked footprints and IFC footprints are levelled the same way (Rotate... still turns them to suit the stand). New Place with a ruler (button in the Buildings list and the ribbon): choose two boundaries and type the distances, for example 5 m from the street and 3 m from the side, and the building moves there as you type. The selected building also shows its distance to every boundary in the plan.
- **Survey and footprint in Building lines, 1.80.0**: load your surveyed site as DWG, DXF or PDF (a PDF asks for its scale, a DXF its units; DWG needs the ODA File Converter) and it sits under the plan. Pick the stand from the closed outlines in the drawing, or trace it by clicking the corners; the building lines are then set on each boundary. For the buildings, either make a footprint from the IFC model, seen from above with patios, balconies, slabs and roof overhangs (you choose what counts), or load a footprint PDF, DXF or DWG and pick or trace the building on the plan. Traced and IFC shapes move and rotate as one piece. The plan zooms with the wheel, pans with the middle or right button, snaps to the drawing's corners, and Calibrate with two points fixes a wrong scale. Drawings are remembered with the project.
- **Three new tools, 1.79.0**, each with the same step bar, ribbon, left bar and icons as the rest of the program. The home screen now has six squares; Site and areas opens a page with Building lines and Area schedule.
  - **Council pack**: step 1 the application details (filled from Project details), step 2 a checklist of what a building plan submission needs (status, file and note per item; add, remove or mark items not needed), step 3 builds a numbered folder with an index sheet and, if you want, one joined PDF. Reports from the program (site plan, drawing register, XA, light and ventilation, coverage and FAR, area schedule, departure motivation) are made for you when an item has no file.
  - **Area schedule**: every room with block, level, unit and type. Fill it from the project rooms, the IFC model, a CSV file or a paste from a spreadsheet. Totals by block and level, by unit and room type, the unit mix, and the floor area that counts toward FAR. PDF and CSV reports.
  - **Building lines**: describe the stand (a rectangle takes two numbers, or enter the corners), set the building line on each boundary, then place the buildings by numbers or by dragging them in the plan. It shows the area inside the building lines, what encroaches and by how much, coverage and FAR (the floor area follows the Area schedule), and writes a departure motivation from the numbers and the reasons you tick. PDF report with the plan.
  - All three are saved in the project file and autosaved, and the keyboard shortcuts (Alt+Right / Alt+Left, Ctrl+H) work in them.
- **Polish, 1.78.2**: icons on the remaining group titles (Products, Fixture schedule, Blocks and buildings); keyboard shortcuts: Alt+Right / Alt+Left for the next / previous step in every tool, F5 to run the check, Ctrl+H for the home screen; and a short quick tour that opens the first time the program starts (File > Quick tour... shows it again).
- **Icons everywhere and visual fixes, 1.78.1**: every step button (Walls, Roof and ceiling, Floors, Hot water pipes, Windows, Air infiltration, Lighting, Hot water and solar, Run the check, Rational design report; Light & Ventilation and Coverage steps; the register steps) now has its own icon, and so do almost all other buttons and every tab (register, costing, materials, schedule). The group title icon no longer overlaps the title text, the Costing products buttons and ribbon labels no longer get cut off, and the left bar uses shorter section names in Costing.
- **Guided steps in every tool, 1.78.0**: Energy (XA), Light & Ventilation and Coverage & FAR now work like the drawing register: a numbered step bar with a one-line hint, one step shown at a time, and Back / Next buttons. Energy (XA) shows one section at a time (Walls, Roof and ceiling, Floors, Hot water pipes, Windows, Air infiltration, Lighting, Hot water and solar, Run the check, Rational design report); the ribbon's Sections menu still jumps to any of them. Light & Ventilation steps through Windows, Doors, Rooms, Results and Plan. Coverage & FAR has three steps (the stand and its limits, the buildings, the result and reports) with where the floor areas come from under More options. The left bar and the ribbon now have rounded corners.
- **A simpler drawing register, 1.77.0**: the Drawings page is now three short steps with a step bar and Back / Next buttons: 1 Who is it for, 2 The drawings, 3 Check and send. Step 2 shows only Add drawing PDFs, Add a whole folder, Remove selected and the list; the sheet index, blocks and houses, Select all, Remove all, all details and the status for many drawings are under More options (which opens by itself when you have several blocks or a sheet index loaded). Step 3 shows the email, what kind of email it is and the sheet index button; reports, orders and client changes are under More email options. A line above the buttons says in plain words whether you are ready to send (a drawing is ticked and the client has an email address), or what is missing.
- **Costing report, 1.76.0**: a combined PDF for the whole costing: the whole-building estimate (cost per m2, the share of each part, and the budget with over / under when you set a target), the building materials by block, and then the full sanitary ware and fixtures schedule with the product photos and totals. Open it from the ribbon (Costing report: Preview, Export PDF) or from the buttons on the Whole building and budget section.
- **Sections in the left bar, 1.76.0**: the Drawing register (Drawings, Orders, Client changes, Sent and revisions) and the Costing (Fixtures, Building materials, Whole building and budget) now list their sections in the left bar instead of tabs along the top.
- **Status line, 1.76.0**: the thin line at the bottom shows the open project (saved or unsaved changes), the register and the costing in use (saved automatically) and whether each is linked to the project. The project link is now only set when you save the project, not just by looking at it.
- **Detail Notes picker icons, 1.76.0**: the catalog picker uses the program's line icons in place of emoji, so it matches the rest of the program in dark and light.
- **Plan key fixed, 1.76.0**: the key on the floor plan page takes the height its text needs and no longer runs into the room count below it.
- **Tidier top bar and menu icons, 1.75.1**: the logo is now exactly centred over the four squares, and the Light/Dark button and the Online AI label are smaller. The Switch tool menu has an icon for every tool.
- **Left bar shows only the tool you are in, and Switch tool, 1.75.0**: inside the Drawing register, Costing or Detail Notes the left bar lists only that tool (plus Project, except in Detail Notes), and inside SANS it lists Light & Ventilation, Energy (XA) and Coverage & FAR together. Detail Notes also shows its Build submission pack button. At the top of the bar, Home returns to the four squares and the new "Switch tool" menu jumps straight to any other tool without going home first.
- **Four squares to start, 1.74.0**: the program now opens on just four big squares: Drawing register, Detail Notes, Costing and SANS. SANS opens a second screen with Light & Ventilation, Energy (XA) and Coverage & FAR. The left bar, the ribbon (New, Open, Save...) and the step strip only appear once you are inside one of them, and the Home button at the top of the left bar (or Back on the SANS screen) returns you to the squares. The old overview is now the Project page in the left bar. The program no longer asks you to start a project when it opens; File > New or Open is still there.
- **New home screen, 1.73.0**: the program now opens on one big home screen with a larger logo at the top. Square tiles open the Drawing register, Detail Notes and Costing, and a SANS box holds Light & Ventilation, Energy (XA) and Coverage & FAR. The project details, location and reports are further down the same page.
- **Link to the project is visible, 1.72.2**: under the Register: and Costing: lists a line says whether the open project is linked: "Linked to project X" (button Unlink), "Not linked yet. Saving the project links it" (button Link now), or "Not linked: this stays separate and the project keeps no copy" (button Link to this project). Opening a project that has no link keeps the register or costing you are working in, and it only links when you save or press Link now.
- **Costing works on its own, 1.72.1**: the Costing tab (now marked (WIP)) has a Costing: list at the top with + New costing..., Rename..., Delete, Save a copy... and Open a copy.... Each costing is kept by the program and saves itself, with its products, fixtures, materials and budget, so it no longer depends on the project that is open. You can still pull rooms, fixtures and sizes from the open project as before. Costings already inside older projects are picked up automatically.
- **The drawing register works on its own, 1.72.0**: at the top of the register tab there is now a Register: list with + New register..., Rename..., Delete, Save a copy... and Open a copy.... Each register is kept by the program and saves itself after every change and the moment you press Send, so its issues, revisions, sheet index, orders and changes no longer depend on the project that is open. Opening or starting a project does not wipe the register; a project remembers which register it used. Registers already inside older projects are picked up automatically. Save a copy writes a backup file (.mcpreg) you can open on another computer. Type the job number as the register name (for example ODN 14243) and it is also used as the title.
- **Status for many drawings at once, 1.71.3**: under the drawing list, "Status for many drawings at once": pick or type a status (For information, For approval, ...) and press Set for ticked drawings, Set for this block, or Set for everything. You can still change a single drawing in the Status column (Show all details).
- **Earlier issues remembered per block, 1.71.2**: drawings you sent in an earlier issue stay in the sheet index as Issued earlier, with their revision and date, even when you only send other blocks today. This is now matched block by block, so the same drawing number in two blocks (for example 101 in Block A and in Block C) is not mixed up. The line above the tables also says which blocks were issued earlier.
- **Sheet index on/off button, 1.71.1**: under the email there is a blue button, "Sheet index (what is still to come): ON". Click it to turn the sheet index off when you only want to send one batch of drawings; the email then lists just the drawings you are sending. Click again to bring it back. It is on by default.
- **Shorter email, grey tabs, rounded labels, 1.71.0**: the list of drawings in the email now runs in two columns, so a block of 9 drawings takes about half the height, with the revision and size under each title. The Issued today, Issued earlier and Not yet issued labels are rounded. Each report (and other list item) now sits on a light grey tab with the red edge. On a phone the two columns stack under each other.
- **Sheet index always on, 1.70.8**: the sheet index and the still-to-come drawings are now always put into the email whenever something is not in the issue. A project saved while the old "Add a sheet index" tick box was switched off kept it off with no way to turn it back on; that setting is gone.
- **Email written fresh when a project opens, 1.70.7**: when you open a saved project the email is now written again from the drawings (so the sheet index and the still-to-come drawings appear), unless you had changed the text by hand. Before, an opened project kept the old saved email text and never updated it.
- **Issued by shows only the name, 1.70.6**: in the drawing register (the page and the PDF), Issued by now shows just your name, without your position and the rest of the signature.
- **One list of everything in the email, 1.70.5**: when some drawings are still to come, the email no longer has two lists. It has one table per block or house listing every drawing by number and name, with its revision, size and scale, marked Issued today (red), Issued earlier or Not yet issued, under a line such as "Issued today: Block A (3 of 3). Still to come: Block B (5 drawings)". Drawing numbers with spaces (like A 101) and titles with extra spaces now also appear in the table.
- **Sheet index fixes, 1.70.4**: when blocks use the same drawing numbers (for example 101 and 102 in Block A, C and D), loading the sheet indexes no longer skips the later blocks; each block now keeps its own list. A drawing PDF is matched to the block that is open first. If you changed the email text by hand it does not update itself, so an orange note now says so above the email, and loading drawings tells you to press Write it again to bring the sheet index in.
- **Revised, new set or these drawings, 1.70.3**: under the email on the register page, "This email is:" lets you choose Revised drawings (shows what changed since the last issue), A new set of drawings, or These drawings. With the last two the email opens with "Please find attached a new set of drawings..." or "Please find attached the following drawings...", has no "what changed" part and just lists the drawings; the register PDF follows the same choice. Until you choose, it is Revised when something was sent before, otherwise a new set.
- **Load sheet indexes from a folder, 1.70.2**: on the register page, "Load all sheet indexes from a folder..." lets you point at the folder where your sheet indexes are saved. Every sheet index inside it, also in the Block A, Block C, Block D... sub folders, is found at once (a file counts when its name has the word index, drawing list or register). The block or house is named from the file ("Block A sheet index.pdf" gives Block A) or, when the file is just called "Sheet index", from the folder it sits in. You can still change each name before adding. The file picker is still there as "Pick sheet index files...".
- **Simpler drawings step, 1.70.1**: step 2 of the register is now two plain actions. A: "Load the sheet index(es)..." lets you pick the sheet index file of every block or house at once (PDF, csv or xlsx) and name each one; every drawing in them is listed as still to come. B: "Add drawing PDFs..." for what you are sending today; each PDF is matched to the sheet index by its drawing number (even if the dashes or spaces differ) and ticked to send automatically. Whatever you do not send is listed for the client as still to come. Blocks and houses now have your own names: "+ Add a block or house..." asks for the name, there are Rename and Delete buttons, and the starting block is called Main house (and takes the name of the first sheet index you load).
- **Sheet index as a PDF, 1.69.2**: "Import a sheet index..." now also reads a sheet index that is a PDF. It finds the rows and columns from the position of the text (drawing number, name, revision), with or without a heading row. A scanned PDF (a picture) cannot be read.
- **Import a sheet index, 1.69.1**: on the register page, "Import a sheet index..." reads the sheet index (list of layouts) you export from Archicad for another block or house (.csv, .txt, .tsv or .xlsx), finds the number, name and revision columns by their headings, and adds those drawings as still to come for the block you choose. The email and PDF then tell the client what is coming.
- **Send one block, tell the client the rest, orders and changes apart, 1.69.0**: on the register page there is now a tick box for each block or house under "Send now". Tick the blocks you are sending today; the ones you leave unticked are listed in the email and the PDF as still to come, with a line such as "Issued today: Block A. Still to come: Block B (3 drawings), Block C (2 drawings)". New button "Drawings still to come...": type the drawings that are not ready yet (number and name, one per line) and they show as Not yet issued until you add their PDFs. The sheet index is now automatic (no tick box). The Orders and changes tab is split into two tabs, Orders and Client changes, and each can be listed in the email and the PDF with its own tick box (off by default).
- **Sheet index, orders and changes on their own, 1.68.0**: the register email and the register PDF can now carry a sheet index, listing every drawing of every block or house as Issued today, Issued earlier (with its revision and date) or Not yet issued, so the builder or client sees what has been sent and what is still to come. It works for a single house as well (it only shows when there is more than what is issued today). Tick or untick it on the register page. The orders and changes list is no longer put into the email and the PDF unless you tick "Also list orders and changes"; it stays in its own list.
- **Wider email, 1.67.4**: the whole register email is about 6% wider (680 instead of 640 pixels) on a computer, so the cards, tables and the signature banner are all a little bigger, and the portrait with them. The text inside the banner keeps its size relative to the banner.
- **Smarter signature, 1.67.3**: the text in the signature banner is larger so it stays readable when the banner shrinks, and the email address now sits right next to the phone number. On a narrow screen (a phone, or a small preview window) the banner is replaced by plain readable text with the same clickable phone, email and website.
- **Clickable signature, 1.67.2**: the phone number, email address and website in the signature banner are now real links in the sent email (tap the number to call, the email to write, the website to open it). The name is no longer repeated in front of the phone number.
- **Signature follows the width, rounded edges, 1.67.1**: the signature banner now stretches and shrinks with the email preview window, and with the email on a phone or a wide screen (up to a sensible maximum), and has rounded corners like the other cards.
- **Email signature banner, 1.67.0**: register emails now end with the MCP signature banner (background, logo, divider and website are fixed). Under Issued by > My email signature... each user enters their own name, position, phone and email and chooses their own photo once; a live preview shows the banner. The banner is a picture, so its text is not clickable.

The Light & Ventilation toolbar is grouped: the rules on the first line, "Model source" (the two IFC tick boxes) on the second, with less used settings under More options and the importers under Import. The left menu scrolls on a short window and keeps the Build submission pack button in view. The province borders and the coast are rounded off and drawn with smooth, anti-aliased lines.

Empty lists tell you what to do, and you can drag drawing PDFs (or a folder), an IFC model or a project file onto the window. Removing drawings or revisions no longer asks first: a message at the bottom offers Undo. "PDF saved" messages are now small notes with an Open folder button. - **Sent and revisions, drawings list, revision reader, 1.63.5**: the history lists the sheets where changes were made; the register reads each sheet's own revision table; the drawings list has Select all, Remove selected, Remove all and a red highlight; revisions can be deleted, started fresh or continued from an earlier email.

The change IDs are not printed in front. Which changes are new is still worked out from the dates, and from the highest change ID that was sent when a row has no date.

Codes that lead a description ("01", "Rev B -", "A:") are dropped. New drawings are listed the same way. In Orders and changes the line has one drawing per line. The email shows the drawing changes once, and the Orders and changes section only adds the kind of change.
- **Only described changes, 1.62.1**: "Get changes from the drawings" now brings in only drawings whose revision column has a description of what changed.
