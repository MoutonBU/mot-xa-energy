# MOT XA Energy (private)

Release a new version: edit mot_xa_energy.py, set the number in the BUILD file one higher, commit and push.
    

GitHub builds MOT_XA_Energy_Setup.exe and attaches it to the Release (Actions tab shows progress).
Tag number = build number; the program offers the update when the tag is higher than the installed one.

One-time in the program: Menu > Update settings (GitHub): repo MoutonBU/mot-xa-energy plus a fine-grained token (this repo only, Contents: Read-only).
